# Poverty eradication
기부한 돈이 어디에 어떻게 쓰였는지 사진·영수증과 알림으로 확인할 수 있게 도와주는 SW

`index.html`을 브라우저에서 열어 실행합니다. 기부처와 내역은 가상 예시이며, 데이터는 현재 브라우저에만 저장됩니다.

- 기부처별로 날짜순 잔액을 검사합니다. 같은 날의 기부금은 사용할 수 있지만 이후 날짜의 기부금은 앞당겨 사용할 수 없습니다.
- 기부 기록과 사용 내역을 수정·삭제할 수 있습니다. 기부일·금액·기부처를 바꾸거나 삭제할 때도 기존 사용 내역의 잔액을 검사합니다.
- 사용 내역 수정 시 기존 첨부를 유지·삭제하거나 새 파일로 교체할 수 있습니다. 연결된 알림은 수정 시 갱신되고 삭제 시 함께 삭제됩니다.
- 실행 취소는 직전 변경과 관련된 기록·증빙·알림만 복원합니다. 이후 읽은 알림과 다른 탭이 추가한 기록은 유지합니다. 같은 기록이 다른 탭에서 수정되거나 잔액이 부족해지면 취소를 차단합니다. 다음 기록 변경이나 새로고침 전까지 사용할 수 있습니다.
- 같은 주소로 연 탭은 변경을 자동으로 반영합니다. 저장을 탭별로 순서대로 처리하고, 오래된 상태에서는 저장을 차단합니다. 열어 둔 입력창에서 충돌 안내가 나오면 창을 닫고 최신 기록을 다시 열어 주세요. 안전한 저장에는 Web Locks를 지원하는 최신 브라우저가 필요합니다.
- 화면 하단의 **백업 내보내기**로 기록·첨부·알림을 JSON 파일에 보관할 수 있습니다. **백업 복원**은 파일 형식·날짜·금액·연결 관계·잔액을 검사하고 복원 내용을 보여준 뒤 현재 기록을 교체합니다. 파일은 최대 20MB이며 브라우저 저장 공간이 부족하면 기존 기록을 유지합니다. 복원도 실행 취소할 수 있습니다.
- PDF 첨부는 앱에서 페이지별로 미리 볼 수 있습니다. PDF.js가 로컬에 포함되어 인터넷 연결 없이 동작합니다. 암호가 있거나 표시하지 못하는 PDF는 다운로드해 확인할 수 있습니다. 라이브러리 정보와 라이선스는 `vendor/pdfjs/`에 있습니다.
- 등록된 금액과 증빙은 미검증 상태입니다. 실제 기부금 사용이나 첨부 자료의 진위를 확인한 결과가 아닙니다.

기능 검증은 Node.js에서 `node --test tests/records.test.cjs`로 실행합니다.
